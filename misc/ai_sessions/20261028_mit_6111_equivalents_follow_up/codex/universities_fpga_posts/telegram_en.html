Beyond an introductory FPGA lab

An FPGA class is a starting point. It does not tell us whether students can build a non-CPU pipeline, handle backpressure, verify corner cases or explain negative slack in an ASIC timing report.

New bilingual report: 49 criteria, seven evidence tables, 90 universities and two shared programs. It separates non-CPU pipelines from CPU projects; simulation assertions from formal checks; FPGA timing from ASIC STA; and using EDA tools from implementing them.

Scores measure documented coverage. A missing public lab is not proof that a topic is not taught. The most useful output is the set of linked assignments and the proposed learning sequence.
