# Материалы руководства BGM

- `bgm_workflow_manual_codex_ru.html` — самостоятельная HTML-страница для просмотра в браузере, с оформлением и оглавлением.
- `bgm_workflow_manual_codex_ru.md` — тот же материал в Markdown для репозитория BGM или GitHub Wiki.
- `bgm_workflow_manual_wordpress_codex_ru.html` — HTML-фрагмент статьи без `html`, `head`, внешних библиотек и JavaScript; предназначен для HTML-режима WordPress.

Все три версии используют абсолютные адреса исходных иллюстраций на
`https://www.panchul.com/bgm_workflow_manual/20261011/`.
Для загрузки картинок нужен доступ к этому сайту. Нажатие на картинку
в самостоятельной HTML-версии открывает оригинал.

## Публикация

Для GitHub Wiki используйте Markdown-файл: полноценная HTML-страница с CSS
не переносится в Wiki как обычная веб-страница. Для WordPress вставьте
содержимое `bgm_workflow_manual_wordpress_codex_ru.html` в HTML-режим или блок Custom HTML.
Оформление там задаёт тема WordPress; перед публикацией проверьте предпросмотр,
оглавление, таблицы и подписи. Самостоятельный HTML можно выложить на статический
хостинг без преобразования.

Ничего не опубликовано и не добавлено в Git. Рабочие клоны BGM не изменены.

## Редактирование

Общий источник — `research/manual_source.md`. Директивы `@@FIG ...@@`
содержат идентификатор исходного изображения и русскую подпись.
Сборка всех форматов:

```bash
python3 research/build_manual.py
```

Для сборки нужны Python 3, Pillow и доступ к исходным изображениям в
`/home/verilog/bgm_workflow_manual/20261011/`.
Готовые HTML и Markdown не требуют Python.

## Существенные редакционные уточнения

- Учебный upstream соответствует снимкам: `chipdesignschool/basics-graphics-music`.
- В текст добавлена отдельная ветка `student/hyperbola`, хотя демонстрационные
  снимки показывают изменения в `main`. Отличие объяснено рядом с инструкциями.
- Глава 23 описывает LCD 480×272 через OSS CAD Suite: именно эта конфигурация
  выбрана на снимках. Слово HDMI в исходном имени папки не соответствует её содержимому.
- `03_synthesize_for_fpga.bash` также вызывает программирование платы;
  `04_configure_fpga.bash` позволяет повторить его без повторного синтеза.
- Исправлена арифметическая ошибка оригинальной Git-памятки: 3600 секунд — один час.
- Объяснены эффекты `git clean -x`, индекса Git и `checkout --`, а также ограниченная
  переносимость исходной массовой замены табуляций.
- Приложение Б описывает фактическое поведение скриптов снимка `991a4b32`,
  включая различия приоритетов поиска, сортировки и явных переменных окружения.

В `research` сохранены источник, перечень иллюстраций, OCR для анализа снимков,
результаты проверок и локальные изображения предпросмотра. Эти служебные файлы
не нужно публиковать вместе со статьёй.
