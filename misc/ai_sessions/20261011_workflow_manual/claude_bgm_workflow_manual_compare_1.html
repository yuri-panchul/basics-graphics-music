Pros and cons

For a student following along with the pictures

Mine

Pros

  • Text and pictures agree from start to finish, and almost every step has a screenshot (176 of 177).
  • Figure numbers run in order, so “Рис. 12.6” is easy to find.
  • Keeps your introduction and title layout, with only the typos fixed.
  • Has reference tables theirs lacks: chapters by platform, scripts 01–07, Quartus limits by FPGA family, Gowin report files, OSS CAD Suite tools by FPGA family.
  • Plain HTML that survives a WordPress paste. Its rendering is confirmed in your 129-page Chromium PDF.
  • Consistent Russian terminology (“форк”, 31 times) and shorter sentences overall.
  • Already includes your photos and caption; builds with nothing beyond Python.

Cons

  • Teaches committing to main, because the screenshots do. The branch advice appears only as a tip after the fact.
  • Little troubleshooting: it doesn't say which side is which in a merge conflict, and doesn't mention git merge --abort, the Discard commits trap in Sync fork, or what to send the teacher.
  • Appendix Б is imprecise in four places, and its links follow main, which will drift.
  • Doesn't warn that git clean -dxf can delete a new lab that was never added to Git.
  • No dedicated WordPress fragment, images have no width/height, and the page has no back-to-top links.

Theirs

Pros

  • Appendix Б is the most precise of the two: pinned commit, where each tool's directory goes in PATH, the sort fallback, the early exit when GOWIN_VERSION_DIR is set, both OSS CAD Suite environment files, and Б.5 on what to report.
  • Teaches safe Git habits: a branch per task, git add with an explicit path, git diff --cached, a conflict procedure, stash, --ff-only, and a warning about Discard commits.
  • Explains tool behaviour students will run into: 05 recreates the Quartus run/, Vivado shows its runs as “Not started”, SRAM versus flash, the macOS quarantine prompt.
  • Has a separate WordPress fragment with <figure>/<figcaption> and image width/height.
  • A polished standalone page with a two-column table of contents and a back-to-top button.

Cons

  • 110 Markdown captions are glued to the following image.
  • The WordPress table of contents is numbered twice (“1. 00. Введение”).
  • The text uses student/hyperbola while every screenshot in chapters 9, 10, 12 and 20 shows main.
  • Figure numbers have gaps and one pair is out of order; 36 screenshots are unused.
