What each side should adopt next

  • Codex should keep the competitor’s broad institution discovery, specific course selection, complete cluster roster and regional synthesis, while checking evidence rather than copying ratings.
  • The competitor should adopt explicit source dates, separate hardware/project evidence, campus attribution checks, accessible alternatives for failed links, and local search/filter controls. Its counts should separate confirmed opportunities from “not found” leads.
  • Both should ask course staff for the latest syllabus, actual board checkoffs and project rubrics when public evidence is incomplete. HTTP failures should be logged, not converted into claims of nonexistence; historical laboratory hardware should not be mistaken for a current purchase recommendation.
