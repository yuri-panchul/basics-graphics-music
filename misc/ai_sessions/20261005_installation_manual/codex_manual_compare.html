Дополнительные пробелы, не равные доказанной ошибке

  • Установка Icarus из исходников: не перечислены build-зависимости; PPA, названия архивов Surfer и содержимое релизов нужно проверить перед массовой установкой. Сам факт существования ссылки не доказывает доступность требуемой версии для Ubuntu 22.04.
  • LibreLane: нужен точный каталог с flake.nix перед nix develop, проверка версии, smoke-test и ясное отличие локального результата от готовности к выбранному шаттлу.
  • macOS: нужна практическая оговорка об архитектуре VM, Bash/GNU/BSD и UART; разрешение запуска скачанного приложения не решает несовместимость бинарника с CPU.
  • Готовый top.sof: фраза о рабочем старом облачном файле не подкреплена проверкой и не привязана к точной плате/распиновке. Предпочтительно собрать известный пример для выбранной обёртки.
  • Пути с пробелами: практическое правило короткого ASCII-пути разумно для EDA, но абсолютный запрет для всех программ противоречит собственному примеру C:\Program Files\OpenJDK. Для Quartus полезно отдельно перечислить проблемные специальные символы.
  • Клавиши загрузки: BIOS Setup и разовое Boot Menu не одно и то же. Таблицу клавиш по производителю следует пометить примерами и сверять с конкретной моделью.
  • Количество авторов: 69 имён из git log и 46 записей GitHub API измеряют разное; ни одна цифра сама по себе не опровергает другую. Нужны дата, метод и учёт авторских алиасов.
  • Gowin 1.9.9: утверждение о недостаточности версии для GW5A/GW5AST конфликтует с собственной таблицей «1.9.9 и новее». Нужно различить Education, полную версию и конкретную сборку; один номер семейства релизов не даёт ответа.

4. Преимущества и недостатки обеих редакций

Codex: сильные стороны

  • Новые терминальные инструкции основаны на конкретном RTL, включая отсутствие TX у двух примеров и обратную польскую запись калькулятора.
  • Точные пути и commit, архив входных материалов, контрольные суммы, честное разделение чтения кода и испытаний оборудования.
  • Подробные ограничения обнаружения программ и различия платформ; есть проверки после установки и диагностика.
  • Поиск в каталоге плат, локальные ресурсы, единые фрагменты команд/ссылок/таблиц для трёх языков, автоматические проверки.
  • VM/SSD-ссылки не выдуманы; текущие данные явно запрашиваются у организаторов.

Codex: ограничения и недостающие улучшения

  • Полные страницы старого PDF сохраняют контекст, но мелкие окна трудно читать на телефоне; старый ошибочный текст остаётся виден внутри изображений.
  • Основное содержание показывает только h2. К подразделам minicom, PuTTY и новым примерам удобнее иметь прямые ссылки в оглавлении.
  • Отчёт changes.html доступен только по-русски; переводы основного пособия отсылают к нему.
  • Новый UART-раздел подробен и длинен. Короткий маршрут «выбрать один терминал → подключиться → проверить echo» улучшил бы первое прохождение.
  • Много технических оговорок; нет такой же компактной таблицы всех 01–14, как у Claude, и карты разделов с результатом на плате.
  • Часть EDA-материала осталась проверкой от 5 октября; обновление UART не является новым испытанием всех версий инструментов. Старые снимки каталога/участников требуют периодической пересборки.
  • Исследовательский комплект больше набора страниц для читателя; полезно выпускать отдельный компактный архив без служебных файлов.

Claude: сильные стороны

  • 124 отдельных изображения близко к соответствующим шагам: легче сопоставить кнопку установщика с инструкцией.
  • Подробное содержание и ссылки «наверх», компактная карта учебных разделов, единая таблица назначения скриптов.
  • Три переведённых errata; визуальное различение нового, исторического и непроверенного материала.
  • Доступные объяснения мотивации: почему нужны старые Quartus, зачем «зоопарку» плат общие скрипты, почему SVH можно начать без платы.
  • Все проверенные локальные ссылки целы, дублирующихся id нет. Стиль встроен в HTML, поэтому перемещение страницы не теряет CSS.

Claude: слабые стороны

  • Конкретные неверные команды и переменные особенно опасны именно в хорошем пошаговом тексте: студент естественно копирует их.
  • Недостаточная привязка к commit; обещания кэша и override не совпадают с main, заявленным источником.
  • Обобщения «самая новая», «всё работает», «не нужно больше ничего» скрывают важные условия запуска.
  • Новые UART-лабораторные, DOCX, RRT и статья ещё не интегрированы в сравниваемую редакцию.
  • В image_manifest.txt есть имена файлов, но нет заполненной постраничной атрибуции/контрольных сумм, сопоставимых с manifest Codex.
  • Нет поиска по длинной таблице плат; многократные встроенные стили надо синхронизировать между шестью страницами.
