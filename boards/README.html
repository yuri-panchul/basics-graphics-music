BGM boards at a glance

54 boards, one line each, with the Quartus versions that can actually build them.

The Quartus ranges are measured, shown in green: every installed version was asked whether it can build each board's exact part. Probed here were 13.0sp1, 13.1 and 25.1std under the home directory, 21.1 under /opt, and 26.1.1 Pro. A range carrying a dagger reaches past those versions, so one of its boundaries is not measured — as does every entry for Vivado, Gowin EDA and the Yosys flow, for which the repository states no version requirement at all. Manufacturer is unverified for the same reason.

How each range was established

  • Agilex 3 — only the Pro edition builds it; no older Pro installed
  • Cyclone — every installed version refuses it with error 20005, a licence is required; the board's own project file was written by 9.1 SP2 Web Edition
  • Cyclone II — 13.0sp1 builds it, 13.1 does not
  • Cyclone III — 13.1 builds it, 21.1 does not
  • Cyclone IV E — all four free editions build it
  • Cyclone V — all four free editions build it
  • MAX 10 — 21.1 and 25.1std build it, 13.x do not; the 14.0.2 bound is not measured here
  • MAX II — all four free editions build it
TM1638: always, never or either, from whether each build's wrapper instantiates the module.
Graphics describes what the wrapper wires, not what the board can do.
